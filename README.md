# 💈 OZbarber - Sistema de Agendamento Online

Projeto de um aplicativo de agendamento e gerenciamento para barbearias inspirado no Fresha, com identidade visual moderna baseada em tons de preto, cinza e branco.

## 🎨 Identidade Visual (Minimalista Premium)
- **Cores Principais:** Preto, Cinza Escuro, Cinza Claro e Branco.

## 🚀 Funcionalidades Principais (Escopo)
- [ ] **Agendamento via Link:** Página pública para o cliente final agendar serviços na OZbarber.
- [ ] **Timeline da Agenda:** Painel visual no painel interno para acompanhar os horários de cada barbeiro.
- [ ] **Comanda e Lançamento:** Fluxo para fechar o atendimento e lançar os serviços consumidos.
- [ ] **Módulo de Comissões:** Controle e cálculo automático do saldo de comissão de cada colaborador.

## 🛠️ Stack Tecnológica
- **Framework:** Next.js (TypeScript)
- **Ambiente:** Nuvem (GitHub)
